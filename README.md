# 每日一星

移动端优先的足球球星竞猜与档案网站。每天根据北京时间固定一名球员，用户通过逐步解锁的线索猜出答案，随后阅读三分钟生涯档案并继续追问。

## 已实现

- 20 人数据结构（首屏体验使用完整档案球员池）
- 两次自由输入、第三阶段四选一、直接揭晓
- 中文名、英文名和常用别名匹配
- 当日进度 localStorage 持久化
- 收藏球星卡、生涯时间线、荣誉、推荐比赛和冷知识
- 本地档案问答与来源边界说明
- Wikimedia Commons 图片及加载失败降级卡
- 桌面、平板和移动端响应式布局

## 本地运行

```bash
pnpm install
pnpm dev
```

默认地址：`http://localhost:5173/`

生产构建：

```bash
pnpm build
```
