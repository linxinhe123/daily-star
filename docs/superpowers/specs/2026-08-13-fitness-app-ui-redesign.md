# 每日一星 App 化 UI 重构

## 目标

将当前杂志式长页面重构成成熟移动应用界面。参考 Figma Community 高热度 Fitness App UI Kit 的信息架构，不复制其品牌、图片或专有组件。

## 页面结构

- 固定顶栏：品牌、连续参与天数、用户入口。
- 今日页：简短问候、每日挑战主卡、竞猜进度、线索卡、输入区和近期球星。
- 揭晓页：球员主视觉、关键资料、分段标签（概览、生涯、荣誉、问答），避免所有内容一次铺开。
- 档案页：搜索、分类标签、球员卡片网格。
- 移动端固定底部导航：今日、档案、收藏、关于。
- 桌面端使用左侧导航和中心内容区，保持 App 信息密度。

## 视觉系统

- 背景使用中性浅灰，内容卡使用白色，主色为草地绿，强调色为明亮黄绿。
- 标题使用正常产品字号，不再使用海报级大字、首字下沉或英文眉题装饰。
- 统一 12px 卡片圆角、轻边框、克制阴影和 44px 以上触控目标。
- 球员照片作为内容资产使用，加载失败时显示号码与国旗组成的档案卡。

## 保留功能

- 每日固定球员、三次竞猜、第三阶段四选一、直接揭晓。
- 本地进度保存、球员档案、时间线、荣誉、推荐比赛、本地问答和图片署名。

## 响应式

- 390px：底部导航、单列卡片、紧凑顶栏。
- 768px：双列内容，底部导航仍可用。
- 1024px 以上：左侧固定导航、主内容和右侧辅助栏。
