# Transfermarkt 历史数据导入计划

**目标：** 使用同一套采集流程，将任意球员截至 2025/26 赛季的俱乐部正式比赛数据写入 SQLite。

**方案：** 球员清单只保存 slug、Transfermarkt ID 和页面名；采集器请求详细统计页，解析逐赛事记录后按“球员、赛季、俱乐部”聚合，再事务写入数据库。前端读取数据库导出的静态快照，线上访问不请求 Transfermarkt。

**数据边界：** 保存出场、进球、助攻和分钟；首发、平均评分在 Transfermarkt 未提供时为 null；排除国家队、青年队和 2026/27 及以后赛季。
